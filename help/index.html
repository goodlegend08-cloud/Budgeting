Getting started (first visit)

  1. Categories — make one for each kind of spend (Food, Transport, Utilities…). Optional: give it a default monthly limit.
  2. Budgets — pick a month and set a limit on every category you plan to spend on.
  3. Transactions — record spending as it happens, or press Import to load a spreadsheet you already keep.
  4. Dashboard — see the month at a glance: spent vs budget, the category chart and recent entries.
  5. Salary and Recurring — add your payslip and any repeating bills so they fill themselves in.

Short on time? Skip to step 3 and use Import — categories, budgets and salary records come in one go.

Dashboard

  • Use the month arrows in the header to move between months.
  • Summary cards show what you spent, what you budgeted and what is left for that month.
  • The chart breaks spending down by category; recent activity lists the latest entries.
  • An empty month says Nothing recorded yet for this month — that is normal before you add data.

Transactions (your ledger)

  • Add transaction opens a form: amount, category, date and an optional note.
  • The header shows how many entries match your filters; use the filter row to narrow by month, category or search text.
  • Every row can be edited (pencil) or deleted (trash) from its menu — deletion asks for confirmation first.
  • Export downloads a month as Excel, Import loads data back in (see below).

Budgets (your plan)

  • ‹ › switch months; Today returns to the current month.
  • Cards show Budget · month, Spent in budgets and Left.
  • ≈ ₱X/day tells you what you can spend per day until the month ends; Plus ₱Y outside budgets counts spending that has no limit.
  • The pencil on any category sets a limit for that month only — Use category default reverts it.

Salary (payslips)

  • Enter label, pay date and gross pay, then use + Add line or the preset chips (Withholding tax, SSS, PhilHealth, Pag-IBIG…) for deductions.
  • Net pay updates live while you type.
  • Split into 2 paydays — 8th & 23rd saves two half-pay records for that month instead of one (DTR-style paydays). The preview shows both amounts before you save. This option appears when creating, not when editing.
  • The header badge Next payday always counts down to the next 8th or 23rd.

Recurring (repeating bills)

  • Create an item with amount, category, frequency and start date — the first transaction is generated right away and the next due date is shown.
  • A backdated start generates the whole catch-up batch so past months are not empty.
  • Pause stops future generations (a badge shows the state); Resume restarts them.
  • Deleting a recurring item keeps the transactions it already created.

Categories

  • Name, icon, colour and an optional default monthly limit.
  • Archive hides a category from lists without losing history.
  • Delete is blocked while entries still use it — the button reads Delete (has entries).

Import (Excel / CSV / JSON)

  1. Transactions → Import and choose a .xlsx, .xls, .csv or .json file.
  2. Check the summary: categories, transactions, budget limits, salary records — plus Entries to replace and Limits to replace when a file marks outdated rows.
  3. Press Import. Duplicates are skipped, marked rows are replaced, budget limits are updated.

Supported layouts: your dashboard workbook (month tabs with Block sections) and plain tables with headers like Date · Description · Category · Amount (optional Budget column). Everything is parsed inside your browser — nothing is uploaded.

Errors appear under the file picker and list up to five issues at once (field: message). If you edit a row in Excel and re-import, delete the old row first — Excel files carry no “replace” list, only JSON exports do.

Export (download as Excel)

  1. Transactions → Export.
  2. Pick the month & year you want.
  3. Press Download .xlsx — the file is named budget-export-YYYY-MM.xlsx.

The workbook contains six sheets:

  • Summary — totals for that month (spent, budgeted, left, net pay).
  • Transactions — date, category, type, amount, note.
  • Budgets — limit, spent and left per category (including spend that had no limit).
  • Salary — payslips dated that month, with net pay.
  • Categories — everything, with default limits.
  • Recurring — repeating items and their next due dates.

Your data

  • Everything lives in this browser only (local database) — there is no account and no server copy.
  • Clearing site data, or using a different browser or device, means starting fresh there.
  • Back up often: Export your months to Excel and keep the files. Re-importing a JSON export restores everything.
  • Currency defaults to the peso (₱); amounts display with the narrow peso symbol everywhere.

Sample data file for trying the importer: budget-import-2026.json

FAQ

Why does my budget say “Plus ₱X outside budgets”?

Spending in categories that have no limit for that month. Set a limit and it moves into the budgeted totals.

Can I split every payslip into two?

Yes — tick Split into 2 paydays — 8th & 23rd when creating a salary record. Each half is saved as its own record.

Import says “No budget rows found”.

The workbook needs a label column and an amount column (or the Block layout). Check the first rows and adjust headers, then try again.

Re-importing the same file is safe.

Duplicates are skipped; only rows the file marks for replacement are overwritten.

Data is stored locally in your browser.
